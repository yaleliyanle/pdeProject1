# 本科版报告与复现说明

本文件夹提供英文和中文 coursework 的 LaTeX 源文件与 PDF。两份报告采用同一条主线，原项目的模拟代码、数据和报告仍保留在上一级目录。

## 阅读主线

1. **哪种方法能更准确地逼近同一条随机路径？** 用 GBM 精确解比较 EM 和 Milstein。步长缩小 16 倍时，误差分别约缩小 4 倍和 15.6 倍，让半阶与一阶具有直观含义。
2. **路径更准确，均值也一定更准确吗？** 两种方法的均值偏差实际上相同。用解析期望和控制变量处理前后的标准误差解释这个结果，并检查分布和负终值频率。
3. **没有精确解时，怎样判断结果是否可信？** 用三种参考网格检查非仿射模型的强斜率是否稳定，解释为什么需要看涨收益，以及为什么细网格弱差尚无法从抽样噪声中分辨。

正文不再叙述修订过程，也不把自选的 10% 比例当成通过标准。五个控制变量的详细公式留在原代码中；正文只解释零均值控制量如何减少抽样噪声。没有新增高级算法。

## 唯一补充实验：路径数与抽样不确定性

`sample_size_study.py` 读取原 `results/nonaffine_terminals.npz`，固定粗网格 N=64、参考 N=8192、执行价 K=100，依保存顺序取前 10,000、40,000、100,000 对终值。

| 路径数 | 配对收益差的标准误差 | 95% 区间是否跨零 |
|---:|---:|:---:|
| 10,000 | 0.005149 | 是 |
| 40,000 | 0.002592 | 是 |
| 100,000 | 0.001633 | 是 |

路径数增加四倍时，标准误差约减半，符合 1/√M 的关系。三组估计使用嵌套样本，彼此相关，不是独立重复实验。网格不变，所以均值估计变小不能解释为离散偏差减小。完整样本的均值和标准误差已与原结果核对。

脚本还整理两张已有数据表：不同参考下的强斜率，以及 GBM 控制变量处理前后的标准误差。这两张表不涉及新模拟。`translate_figures.py` 用已有数据重绘五张中文图，也没有新增实验或随机抽样。

## 结论边界

- GBM 已用模拟验证强阶和均值弱阶。非仿射模型的细网格收益差区间跨零，报告不强行拟合完整网格范围的弱阶；区间跨零也不证明偏差为零。
- 非仿射模型的对数 EM 在每个步长下都精确保留价格均值，因此均值只能用于实现检查。看涨收益没有同样的恒等式，能够反映均值看不到的分布差异。
- 负终值频率是各网格各方法 0/160,000。原记录没有保存 GBM 路径中途曾为负的频率；报告明确区分两者，详见 `positivity_check.json`。
- 数值参考加密提供敏感性证据，不构成未知精确误差的上界。置信区间只衡量抽样不确定性。
- 提供的 problem pack 没有 AI policy 全文。AI 致谢依据用户已确认课程允许 AI，如实说明 Codex 的实际参与，不加入未经确认的独立审核声明。

## 编译与复现

在本文件夹中运行：

```sh
python3 sample_size_study.py
python3 translate_figures.py
tectonic --keep-logs Coursework_Undergraduate.tex
tectonic --keep-logs Coursework_Undergraduate_中文.tex
```

Python 需要 NumPy 和 Matplotlib；中文图使用 Noto Sans CJK SC。中文 LaTeX 使用 Noto Serif CJK SC、Noto Sans CJK SC 和 Noto Sans Mono CJK SC。图表已经随附，只编译 PDF 不需要重新运行 Python。

原模拟需要时可在上一级目录运行 `run_all.py`，但本次没有重跑。不要直接用原 `build_report_data.py` 覆盖本目录的文字宏，它仍会生成旧版的 10% 表述。更新数据时需保留本版解释。

`results/sample_size_study.json` 保存完整结果、源数组 SHA256 和全样本核对状态，CSV 便于直接查看数值。`checks/validation.json` 与 `checks/page_review.png` 记录当前 PDF 检查。
