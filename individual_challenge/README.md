# Individual Challenge artifact

This folder turns the issue “positivity analysis was verbal” into a quantitative before/after result.

- `positivity_before_after.png`: upload-ready figure.
- `positivity_before_after.pdf`: vector version.
- `submission.md`: complete result, caption, and short database text.
- `build_before_after.py`: reproducible figure generator using saved CSV data.

The script performs no new simulation. It verifies all 16 saved method/grid counts before building the figure.
