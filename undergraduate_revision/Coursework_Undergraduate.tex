\begin{abstract}
This report asks three questions: which method follows a given random path more accurately, whether more accurate paths also give a more accurate mean, and how to assess accuracy without an exact solution. Geometric Brownian motion (GBM) provides an exact benchmark for Euler--Maruyama (EM) and Milstein. Their measured terminal strong orders are \GBMEMRate{} and \GBMMilRate{}, while both have the same first-order bias in the mean. A non-affine stochastic-volatility model then requires a numerical reference. Three nested reference grids give empirical strong slopes close to one half, but fine-grid call-payoff differences cannot be distinguished reliably from sampling noise. One sample-size study, using existing paired terminal samples, illustrates how additional paths reduce this uncertainty without removing time-discretisation bias.
\end{abstract}

\section{Introduction and theoretical background}
The problem pack uses strong and weak convergence, sampling uncertainty and nested grids to assess SDE methods \cite{pack}. GBM is a useful starting point because its exact solution lets us check the implementation. The non-affine model then shows how this approach changes when an exact sampler is unavailable.

The results follow three questions. First, how accurately does each method follow the same random path (Section~\ref{sec:question-path})? Second, does a better path approximation also give a better mean (Section~\ref{sec:question-mean})? Third, how can a calculation be assessed without an exact solution (Section~\ref{sec:question-reference})? Throughout, increasing the number of time steps $N$ improves time resolution, while increasing the number of paths $M$ improves statistical precision.

\subsection{GBM and its exact transition}
For $S_0>0$, the It\^o SDE and log transformation are
\begin{align}
dS_t&=\mu S_t\,dt+\sigma S_t\,dW_t,\\
dX_t&=(\mu-\tfrac12\sigma^2)\,dt+\sigma\,dW_t,\qquad X_t=\log S_t.
\end{align}
It\^o's correction is essential: omitting $-\sigma^2/2$ changes the mean.
Integration gives
\begin{equation}
S_t=S_0\exp\{(\mu-\tfrac12\sigma^2)t+\sigma W_t\}.
\label{eq:exact}
\end{equation}
Thus $S_T$ is lognormal, with
\begin{align}
m&=\mathbb E[S_T]=S_0e^{\mu T},\\
v&=\operatorname{Var}(S_T)=S_0^2e^{2\mu T}(e^{\sigma^2T}-1),\\
q_p&=S_0\exp\{(\mu-\tfrac12\sigma^2)T+\sigma\sqrt{T}\Phi^{-1}(p)\}.
\end{align}
For the chosen GBM baseline $S_0=100$, $\mu=0.05$, $\sigma=0.30$, $T=1$,
$m=105.1271$ and $v=1040.7868$ (rounded). GBM parameters are experiment choices; the non-affine parameters on page~\pageref{sec:protocol} are prescribed by the problem.

\subsection{Three methods on a common Brownian path}
Let $h=T/N$, $\Delta W_n\sim N(0,h)$. Exact simulation uses
\begin{equation}
S_{n+1}=S_n\exp\{(\mu-\tfrac12\sigma^2)h+\sigma\Delta W_n\}.
\end{equation}
The price-based EM and scalar Milstein updates are
\begin{align}
S_{n+1}^{E}&=S_n^{E}(1+\mu h+\sigma\Delta W_n),\label{eq:em}\\
S_{n+1}^{M}&=S_n^{M}\{1+\mu h+\sigma\Delta W_n+
\tfrac12\sigma^2[(\Delta W_n)^2-h]\}.\label{eq:mil}
\end{align}
The extra term follows from $\tfrac12 b(S)b'(S)[(\Delta W)^2-h]$ with $b(S)=\sigma S$ \cite{higham}. Under the usual regularity assumptions, terminal strong orders are $1/2$ and $1$; weak order is $1$ for suitable smooth test functions. Applying EM to the GBM log price instead is exact at grid points. Its additive-noise Milstein correction vanishes, so it cannot demonstrate a nontrivial order-one comparison.

\section{Monte Carlo methodology}
\subsection{Coupling and uncertainty}
Generate independent paths on the finest grid. A coarse Brownian increment is the sum of the corresponding fine increments, so
\begin{equation}
\Delta W_n^{(h)}=\sum_{j=nr}^{(n+1)r-1}\Delta W_j^{(\delta)},
\qquad h=r\delta.
\label{eq:coupling}
\end{equation}
For GBM, the exact terminal value uses the same total $W_T$.
For non-affine volatility, coarse and reference states use the same paired Brownian drivers. Independent random numbers across resolutions would introduce a nonvanishing path mismatch and invalidate a strong-order experiment.

For $M$ independent paths, define $A_i(h)=|S_{T,i}^{(h)}-S_{T,i}^{\rm ref}|$.
The terminal $L^1$ strong-error estimator and its approximate 95\% interval are
\begin{equation}
\widehat e_s(h)=M^{-1}\sum_i A_i(h),\qquad
\widehat e_s(h)\ \pm\ 1.96\,s_A/\sqrt M.
\end{equation}
The observed order is the least-squares slope of $\log\widehat e_s$ against $\log h$ over an explicitly reported window. Points at different $h$ are correlated because of coupling; the slope is descriptive, and no independent-regression confidence interval is claimed.

For a payoff $\varphi$, use signed paired differences
\begin{equation}
D_i(h)=\varphi(S_{T,i}^{(h)})-\varphi(S_{T,i}^{\rm ref}),\qquad
\widehat b(h)=\overline D,\qquad
{\rm CI}_{95}=\overline D\pm1.96\,s_D/\sqrt M.
\end{equation}
The weak error is $|\mathbb E[D]|$, not $\mathbb E|D|$. Signed intervals are retained, including those crossing zero. A log--log trend in an absolute noisy estimate is not sufficient evidence of an order. These intervals quantify sampling error, not the time bias of a numerical reference.

\subsection{Resolving GBM weak bias}
For both schemes, the conditional expected multiplier is $1+\mu h$. Consequently
\begin{align}
\mathbb E[S_N^{E}]=\mathbb E[S_N^{M}]&=S_0(1+\mu h)^{T/h},\\
b_{\rm exact}(h)&=S_0(1+\mu h)^{T/h}-S_0e^{\mu T},\label{eq:weak}\\
b_{\rm exact}(h)&=-\tfrac12 S_0e^{\mu T}\mu^2T\,h+O(h^2).
\end{align}
This identity proves first-order weak bias for the mean in this nondegenerate baseline. It is a validation target, not a Monte Carlo estimate.

The simulation also forms zero-mean control variates $C_i$ and estimates
$\overline{D-\beta^\top C}$. The coefficients $\beta$ are fitted on a separate pilot sample and then held fixed, so the production estimate remains unbiased. Both raw and controlled intervals are retained in the CSV. The pilot is excluded from reported production sample sizes. A short explanation is given on page~\pageref{sec:gbmweak}; the five implemented controls and their coefficients are documented in the supplied \texttt{gbm.py} and saved results.

\section{Model and experimental protocol}\label{sec:protocol}
\subsection{Non-affine stochastic volatility}
Write $X=\log S$, and use the prescribed system
\begin{align}
dX_t&=\{\mu-\tfrac12g(Y_t)^2\}\,dt+g(Y_t)\,dW_t^{(1)},\\
dY_t&=\kappa(\theta-Y_t)\,dt+\xi\sqrt{1+Y_t^2}\,dW_t^{(2)},\\
g(y)&=\sigma_{\min}+\frac{\sigma_{\max}-\sigma_{\min}}{1+e^{-y}},
\qquad d\langle W^{(1)},W^{(2)}\rangle_t=\rho\,dt.
\end{align}
\begin{table}[H]\centering
\caption{Prescribed non-affine benchmark.}
\begin{tabular}{cccccc}\toprule
$S_0$ & $Y_0$ & $\mu$ & $\kappa$ & $\theta$ & $\xi$\\\midrule
100 & 0 & 0.05 & 2 & $-0.2$ & 0.6\\\midrule
$\rho$ & $\sigma_{\min}$ & $\sigma_{\max}$ & $T$ & $X_0$ & strike $K$\\\midrule
$-0.7$ & 0.10 & 0.50 & 1 & $\log 100$ & 100\\\bottomrule
\end{tabular}
\end{table}
From independent standard normals $Z_1,Z_2$, form
\begin{equation}
\Delta W^{(1)}=\sqrt h Z_1,\qquad
\Delta W^{(2)}=\sqrt h(\rho Z_1+\sqrt{1-\rho^2}Z_2).
\end{equation}
The implemented EM step is simultaneous at the left endpoint:
\begin{align}
X_{n+1}&=X_n+[\mu-\tfrac12g(Y_n)^2]h+g(Y_n)\Delta W_n^{(1)},\\
Y_{n+1}&=Y_n+\kappa(\theta-Y_n)h+\xi\sqrt{1+Y_n^2}\Delta W_n^{(2)},\\
S_{n+1}&=\exp(X_{n+1}).
\end{align}
The use of $Y_n$ in both updates matters. Replacing it by $Y_{n+1}$ in the first equation changes the discretisation. The logistic implementation avoids exponential overflow, and finiteness and positive prices are checked during simulation.

\subsection{Grids and reproducibility}
\input{results/protocol_table.tex}
All calculations use double precision and fixed NumPy generators. Production paths are processed in batches to bound memory. Seeds, batch sizes, runtime versions, elapsed times, and full precision results are stored in the accompanying JSON files. No external market data are used. GBM compares exact, EM, and Milstein on price; the non-affine experiment uses EM with successively finer references. The payoff is $\varphi(S)=(S-100)^+$, an \emph{undiscounted expected call payoff} under the stated model drift. No risk-neutral interpretation or option price is inferred without a pricing measure and discount rate.

\subsection{GBM strong convergence}
\begin{figure}[H]\centering
\includegraphics[width=.92\textwidth]{figures/report_gbm_strong.pdf}
\caption{Coupled GBM terminal $L^1$ error. Error bars are pointwise 95\% Monte Carlo intervals; many are smaller than the marker. Reference lines indicate orders $1/2$ and $1$.}
\end{figure}
\input{results/gbm_strong_table.tex}
The fitted slopes are \GBMEMRate{} for EM and \GBMMilRate{} for Milstein on \GBMFitWindow{}. The observed rates match the theoretical distinction: EM omits the quadratic stochastic increment, whereas Milstein accounts for it. At the finest step, Milstein has a substantially lower pathwise error. This comparison uses exactly the same Brownian paths, so differences between methods arise from the update rules rather than from different realizations of the driving noise.

A half-order method reduces error by about $1/\sqrt2$ when the step is halved; a first-order method approximately halves the error. From $N=64$ to $1024$, the step decreases by a factor of 16. EM's error falls from 0.66641 to 0.16658, a factor of 4.00, close to $\sqrt{16}$. Milstein's error falls from 0.02391 to 0.00153, a factor of about 15.6, close to 16. These are terminal price errors, not maximum errors along the whole path. The exact grid values have no time-discretisation error.

\section{Does a better path approximation give a better mean?}\label{sec:question-mean}
\subsection{GBM weak convergence}\label{sec:gbmweak}
\begin{figure}[H]\centering
\includegraphics[width=.70\textwidth]{figures/report_gbm_weak.pdf}
\caption{GBM mean bias magnitude. Controlled paired estimates are compared with the analytic discrete-mean bias. Raw estimates and intervals remain available in the saved CSV data.}
\end{figure}
\input{results/gbm_weak_table.tex}
For the mean, the answer is no: EM and Milstein have identical analytic biases despite their different strong errors. Each step has the same expected multiplier $1+\mu h$, so equation~\eqref{eq:weak} applies to both. The analytic fitted order is \GBMAnalyticWeakRate{} and the controlled Monte Carlo slopes are \GBMEMWeakRate{} and \GBMMilWeakRate{}. This conclusion concerns the mean observable; it does not say that every payoff has the same bias for both methods.

The purpose of a control variate is to remove sampling noise without changing the quantity being estimated. If $D=S_N^h-S_T$ and a random variable $C$ has known mean zero, then, for a fixed coefficient $\beta$,
\begin{equation}\label{eq:control-simple}
\mathbb E[D-\beta C]=\mathbb E[D].
\end{equation}
When $C$ varies with $D$, subtracting a suitable multiple can make the sample average much less noisy. The implementation uses five such variables calculated from the same Brownian increments. Their coefficients are fitted on 20,000 separate pilot paths and then held fixed for the 160,000 production paths. The detailed formulas remain in \texttt{gbm.py}; they are a computational aid, rather than an additional convergence method.

\input{results/control_se_table.tex}
Table~\ref{tab:control-se} explains the need for variance reduction: EM's raw standard error exceeds the mean-bias magnitude $1.28\times10^{-4}$. Milstein's raw interval already excludes zero. The controls reduce estimation noise; they change neither the time-stepping methods nor their bias. The analytic bias is only a validation target.

\subsection{Distribution and positivity}
\begin{figure}[H]\centering
\includegraphics[width=.76\textwidth]{figures/gbm_distribution.pdf}
\caption{GBM terminal distribution compared with the exact lognormal law. The histogram is a sampling diagnostic; quantiles give a more precise distributional comparison.}
\end{figure}
\input{results/gbm_quantile_table.tex}
The exact-simulation mean is \GBMExactMean{} and its variance is \GBMExactVariance{}; the mean interval is \GBMExactMeanCI{}. The analytic mean is 105.1271 and variance is 1040.7868. Sampling fluctuations in empirical moments and quantiles remain even for exact simulation; they must not be described as discretisation error.

For $S_n>0$, EM becomes negative with one-step probability
\begin{equation}
\mathbb P(S_{n+1}^{E}<0\mid S_n>0)
=\Phi\!\left(-\frac{1+\mu h}{\sigma\sqrt h}\right).
\end{equation}
For Milstein, completing the square gives the multiplier
\begin{equation}
\tfrac12\sigma^2(\Delta W+1/\sigma)^2+
\tfrac12+(\mu-\tfrac12\sigma^2)h.
\end{equation}
It can be negative only if $(\sigma^2-2\mu)h>1$. Here $\sigma^2-2\mu=-0.01$, so Milstein is positive for every $h>0$ in this parameter set. EM has a nonzero theoretical probability of a negative update, although that probability is extremely small for these parameters.

The saved counts are for $S_N\le0$ and are all zero, so the strictly negative counts in Table~\ref{tab:negative-frequency} are also zero. These are terminal frequencies, not counts of paths ever becoming negative: intermediate GBM prices were not recorded by this diagnostic. Zero observed negatives does not prove that EM preserves positivity. Negative prices could distort payoff estimates; clipping them to zero would also change the method. Neither scheme is clipped here.

\section{How can we assess accuracy without an exact solution?}\label{sec:question-reference}
\subsection{Strong differences against a numerical reference}
\begin{figure}[H]\centering
\includegraphics[width=.92\textwidth]{figures/report_nonaffine_strong.pdf}
\caption{Terminal strong differences against three coupled EM reference grids. The reference is numerical, so these are not exact-error curves.}
\end{figure}
\input{results/nonaffine_strong_table.tex}
Against the finest reference, the empirical slope is \NARate{} over \NAFitWindow{}. The result is consistent with approximately half-order strong behavior on this window. Curves bend when a coarse grid approaches a reference grid: two nearly identical discretisations can agree well while both retain a nonzero error relative to the continuous SDE.

If $S^\star$ denotes the unknown exact terminal value, the reverse triangle inequality yields
\begin{equation}
\left|\mathbb E|S_h-S^\star|-\mathbb E|S_h-S_r|\right|
\leq \mathbb E|S_r-S^\star|.
\end{equation}
The right-hand side is unknown. Replacing $r$ by a finer grid measures sensitivity of the benchmark, not that unknown error itself. We therefore compare the fitted slope across references as well as reporting the differences between reference solutions.

\subsection{Why use a call payoff instead of just the mean?}
The continuous model satisfies $\mathbb E[S_T]=100e^{0.05}$. However, the log-EM method also gives this mean at \emph{every} step size. To see why, set $g_n=g(Y_n)$. At the start of the step, $S_n$ and $g_n$ are known and the next increment is $N(0,h)$. Hence
\begin{equation}\label{eq:mean-preservation}
\begin{aligned}
\mathbb E[S_{n+1}\mid\mathcal F_{t_n}]
&=S_n e^{(\mu-g_n^2/2)h}\mathbb E[e^{g_n\Delta W_n^{(1)}}\mid\mathcal F_{t_n}]\\
&=S_n e^{(\mu-g_n^2/2)h}e^{g_n^2h/2}=S_ne^{\mu h}.
\end{aligned}
\end{equation}
Here $\mathcal F_{t_n}$ means the information available at the start of the step. Repeating this calculation gives $\mathbb E[S_N]=100e^{0.05}$. Thus the mean is a useful implementation check, but has zero time-stepping bias for this scheme and cannot reveal its weak convergence rate.

Equal means do not imply equal expected payoffs. For example, a price always equal to 100 and a price equally likely to be 80 or 120 both have mean 100. Their expected call payoffs $(S-100)^+$ are respectively 0 and 10. The call payoff therefore tests more of the terminal distribution than its mean. Unlike the mean, its expectation is not automatically preserved by the log-EM update, so changing the step size can produce a genuine weak bias. This makes it a nontrivial weak observable; it is not the only possible choice, and does not guarantee a measurable bias at every grid.

\subsection{One sample-size study: what do more paths improve?}\label{sec:sample-size}
Fix the coarse grid at $N=64$ and the reference at $N_{\rm ref}=8192$. From the saved terminal arrays, form the paired payoff differences
\begin{equation}\label{eq:sample-size-difference}
D_i=(S_{T,i}^{(1/64)}-100)^+-(S_{T,i}^{(1/8192)}-100)^+.
\end{equation}
Use the first 10,000, 40,000 and 100,000 pairs in their saved order. These nested subsets reuse observations, so the three estimates are correlated; they are not independent repeated experiments. No new paths or alternative seeds are generated.
\input{results/sample_size_table.tex}
For independent paths within each subset, the standard error is $s_D/\sqrt M$. If the sample variance changes little, quadrupling $M$ should halve this error. In Table~\ref{tab:sample-size}, it falls from 0.005149 at 10,000 paths to 0.002592 at 40,000, a ratio of 0.503. At 100,000 paths it is 0.001633, about 0.317 of its initial value, close to $1/\sqrt{10}$. Thus the observed uncertainty decreases at the expected scale.

All three intervals still contain zero. More paths improve precision but do not guarantee that this bias becomes detectable at the available sample size. The decreasing point estimates do not show that the method's bias is decreasing: both time grids are fixed, so all three estimates target the same unknown expected difference. Nor should the 100,000-path estimate be treated as its exact value.

\textbf{Practical conclusion.} Increasing $M$ reduces sampling uncertainty. Increasing $N$ changes the time discretisation. This study addresses only the first effect; it neither establishes a weak time-convergence order nor removes bias in the numerical reference. It explains why unresolved fine-grid payoff differences are a statistical limitation, not evidence that their true bias is zero.

\section{Discussion and conclusion}
\textbf{Path accuracy.} GBM supplies a direct answer because the exact and numerical values use the same Brownian path. The measured strong slopes, 0.500 and 0.991, show the expected advantage of Milstein. Refining the step by a factor of 16 reduces EM's terminal error by about 4 and Milstein's by about 15.6. This compares accuracy at fixed grids; it is not a claim about speed at equal computing cost.

\textbf{Mean accuracy.} More accurate paths do not automatically give a smaller bias for every observable. Both GBM methods have the same analytic first-order mean bias; controlled estimates recover slopes near one. The histogram and quantiles examine distributional features that the mean alone cannot check. The observed negative terminal frequency is zero on all tested grids, while the EM formula still permits negative updates.

\textbf{Accuracy without an exact solution.} For the non-affine model, the strong slopes remain close to one half across three references. Coarse-grid call-payoff differences are distinguishable from sampling noise; the finer-grid differences are not. No weak order is assigned to the full range. The sample-size study confirms that adding paths narrows intervals approximately as $M^{-1/2}$, but all tested sample sizes still leave the $N=64$ payoff difference unresolved.

The calculations therefore answer the three questions at different levels: exact-solution validation for GBM, an analytic explanation of its mean bias, and refinement evidence for the non-affine model. Additional paths cannot correct an insufficiently fine reference, and finer steps alone cannot remove sampling uncertainty. These conclusions concern the stated parameters, terminal error measures and grid ranges.

\section{Python implementation and reproduction}
The following listing states the core mathematical operations. The executable
modules additionally implement batching, control-variate pilot fitting, uncertainty estimates, diagnostics, exports, and plots; their complete source is supplied alongside this report.
\begin{lstlisting}[caption={Core SDE updates and coupled error statistics.}]
import numpy as np

def coarsen(dw_fine, n_coarse):
    m, n_fine = dw_fine.shape
    assert n_fine % n_coarse == 0
    return dw_fine.reshape(m, n_coarse, -1).sum(axis=2)

def gbm_terminal(dw, s0=100., mu=.05, sigma=.3, T=1.):
    h = T / dw.shape[1]
    exact = s0 * np.exp((mu-.5*sigma**2)*T
                         + sigma*dw.sum(axis=1))
    em = s0 * np.prod(1 + mu*h + sigma*dw, axis=1)
    mil = s0 * np.prod(1 + mu*h + sigma*dw
              + .5*sigma**2*(dw*dw-h), axis=1)
    return exact, em, mil

def log_em_step(x, y, dw1, dw2, h):
    # Values on both right-hand sides are at the old time.
    sigmoid = np.exp(-np.logaddexp(0., -y))
    g = .1 + .4*sigmoid
    x_new = x + (.05-.5*g*g)*h + g*dw1
    y_new = y + 2*(-.2-y)*h + .6*np.hypot(1.,y)*dw2
    return x_new, y_new

def mean_ci(values):
    m = len(values)
    mean = np.mean(values)
    half_width = 1.96*np.std(values, ddof=1)/np.sqrt(m)
    return mean, mean-half_width, mean+half_width

# Brownian drivers from independent standard normals:
# dw1 = sqrt(h)*z1
# dw2 = sqrt(h)*(rho*z1 + sqrt(1-rho**2)*z2)
# Strong: mean_ci(abs(s_coarse-s_reference))
# Weak: mean_ci(maximum(s_coarse-100,0)
#               -maximum(s_reference-100,0))
\end{lstlisting}
