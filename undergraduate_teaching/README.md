# 从数值 PDE 课程理解第四题

这份教学指南面向只有概率论基础、没有金融和随机微积分背景的应用数学本科生。它与本科版报告配套，但独立编排，不修改已有报告。

- `任务理解与教学指南.pdf`：中文教学文档。
- `任务理解与教学指南.tex`：LaTeX 源文件。
- `teaching_core.py`：GBM、相关增量、对数 EM、配对误差与置信区间的短小教学实现。
- `sample_size_table.tex`：已有样本量实验结果的排版副本，没有新增实验。

阅读顺序：任务要求 → 最少金融词汇 → 布朗增量 → Itô 修正 → 三个更新公式 → 强弱误差 → 统计不确定性 → 耦合网格 → 非仿射模型与参考 → 后向 PDE 联系 → 现有数据 → 代码与报告组织。

文档明确区分题目要求、推荐扩展、理论结论、直观推导和实验支持的范围。后向 PDE 用于联系课程知识，不要求增加 PDE 求解实验。没有重新运行正式模拟，也没有增加此前约定之外的数值实验。

在本目录执行：

```sh
python3 teaching_core.py
tectonic --keep-logs 任务理解与教学指南.tex
```

第一个命令只用固定小数组检查聚合、更新和统计计算，不验证统计收敛阶；正式实验仍以原项目为准。Python 需要 NumPy；中文编译需要 Noto Serif CJK SC、Noto Sans CJK SC、Noto Sans Mono CJK SC 字体。表格已包含在本目录，因此编译不依赖上一级的数据文件。

指南依据项目内 `source/problem_pack.pdf` 第 1、6–7 页与 Git 提交 `282688a` 对应的本科版报告及原程序编写。当前任务的检查记录保存在 `checks/`。
